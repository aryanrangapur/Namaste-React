

# Namaste React - Course Notes and Assignments

The course takes learners from the basics of React to advanced concepts, building a real-world application along the way.



## Course Project

A complete React application called [FoodFire App](https://foodfire-app.netlify.app/) is developed as part of the course using React.js and Parcel.js. To handle the CORS issue in this application, a separate backend was created:

- [FoodFire Server](https://github.com/chetannada/FoodFire-Server): A backend repository for the app hosted on [Render](https://foodfire.onrender.com).



## Project Structure

- `index.html` - Root HTML file of each chapter project
- `index.css` - Stylesheet for the chapter
- `App.js` - Main component logic
- `.env` - Environment variables used during development
